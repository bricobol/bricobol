## 🎯 WORKFLOW DE MODIFICATION

### Sur PC — scripts PowerShell

**Méthode standard (mono-ligne) :**
```powershell
Clear-Host; $f="js/module-XXX.js"; $enc=New-Object System.Text.UTF8Encoding $false; $c=[System.IO.File]::ReadAllText((Resolve-Path $f).Path, $enc); $c=$c.Replace('OLD','NEW'); [System.IO.File]::WriteAllText((Resolve-Path $f).Path, $c, $enc); node --check $f; if ($LASTEXITCODE -eq 0) { "SYNTAX OK" | clip } else { "SYNTAX KO"; node --check $f 2>&1 | clip }
Astuce | clip : envoie le résultat dans le presse-papiers → Ctrl+V direct dans le chat.

Serveur local pour tester :

powershell
npx --yes http-server -p 8000 -c-1
Puis ouvrir http://localhost:8000

⚠️ PIÈGES POWERSHELL CRITIQUES
Set-Content -Encoding UTF8 ajoute un BOM → casse les accents. Toujours utiliser :

powershell
[System.IO.File]::WriteAllText($path, $content, [System.Text.UTF8Encoding]::new($false))
\r\n ne fonctionne PAS en mono-ligne → utiliser [char]13+[char]10

Emojis : [char]0x1F381 plante. Utiliser :

powershell
[char]::ConvertFromUtf32(0x1F381)
Apostrophes françaises dans les alert() : utiliser " (guillemets) en JS, pas '

Multi-lignes : passer par un fichier _fix.ps1 séparé avec here-string @'...'@ | Out-File; puis exécuter
