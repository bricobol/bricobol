## C'EST QUOI CE PROJET

Application de gestion pour l'association BricoBol.
- 100% web (HTML/CSS/JS vanilla)
- Base de données Supabase
- Fonctionne sur PC, tablette, smartphones (Android via APK)
- Hébergée sur GitHub Pages
- PWA installable (manifest + service worker)

## UTILISATEUR / CONTEXTE

- Association BricoBol (aide solidaire)
- 1 bureau, plusieurs bénévoles
- 2-4 appareils synchronisés
- Utilisation quotidienne
- Développement se fait sur PC (VS Code) — mobile (Acode) possible en secours

## ⚠️ STRUCTURE RÉELLE DU PROJET

Le projet est MONOLITHIQUE : tout le code JS et CSS est
INLINE dans index.html. Il n'y a PAS de dossier js/ ni css/.

Fichiers du dépôt :
├── index.html                 ← TOUT le code (CSS + 18 modules JS inline)
├── manifest.json              ← PWA + 4 raccourcis (shortcuts)

├── .well-known/assetlinks.json
├── .gitignore
└── bricobol-mobile.html       ← Fichier buildé (généré par build.js)

## 🔗 HASH D'URL — NOUVEAU

Le Router supporte maintenant le hash d'URL.

- `bricobol.github.io/bricobol/#agenda` → ouvre l'agenda direct
- `bricobol.github.io/bricobol/#missions` → ouvre les missions
- etc. pour tous les modules
- Priorité au démarrage : hash > localStorage > dashboard
- Le hash est mis à jour à chaque changement de vue
  (history.replaceState, pas de rechargement)
- Le bouton retour navigateur fonctionne (hashchange)

**Fonctions ajoutées dans Router :**
- `_getViewFromHash()` — lit et valide le hash
- `init()` — prend le hash en priorité au démarrage
- `go()` — met à jour le hash
- Listener `hashchange`

**Raccourcis manifest.json ajoutés :**
- Agenda     → /bricobol/#agenda
- Missions   → /bricobol/#missions
- Frais      → /bricobol/#frais
- Cotisations → /bricobol/#cotisations

**Pour utiliser les raccourcis sur téléphone :**
- Soit installer l'APK régénérée (appui long sur l'icône)
- Soit ajouter à l'écran d'accueil via Chrome
