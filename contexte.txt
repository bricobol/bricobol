## 🚨 CHANGEMENT MAJEUR — 23/09/2026

Le projet N'EST PLUS MONOLITHIQUE. Découpé en modules séparés.

## C'EST QUOI CE PROJET

Application de gestion pour l'association BricoBol.
- 100% web (HTML/CSS/JS vanilla)
- Base de données Supabase
- Fonctionne sur PC, tablette, smartphones (Android via APK)
- Hébergée sur GitHub Pages
- PWA installable (manifest + service worker)

## UTILISATEUR / CONTEXTE

- Association BricoBol (aide solidaire)
- 1 bureau, plusieurs bénévoles
- 2-4 appareils synchronisés
- Utilisation quotidienne
- Développement sur PC (VS Code) — terminal PowerShell

## 🎯 WORKFLOW DE MODIFICATION (IMPORTANT)

**MÉTHODE RECOMMANDÉE : scripts PowerShell** (beaucoup plus
rapide et sûr que Ctrl+H manuel).

**Modèle :**
```powershell
Copy-Item js/module-XXX.js js/module-XXX.js.backup; @'
$file = "js/module-XXX.js"
$content = [System.IO.File]::ReadAllText((Resolve-Path $file).Path)
$nl = if ($content.Contains("`r`n")) { "`r`n" } else { "`n" }

$search = '...'
$replace = '...'

if ($content.Contains($search)) {
  $newContent = $content.Replace($search, $replace)
  [System.IO.File]::WriteAllText((Resolve-Path $file).Path, $newContent, [System.Text.UTF8Encoding]::new($false))
  Write-Host "OK" -ForegroundColor Green
} else {
  Write-Host "ERREUR - Pattern non trouve" -ForegroundColor Red
}
'@ | Out-File -Encoding utf8 _fix.ps1; powershell -ExecutionPolicy Bypass -File _fix.ps1; Remove-Item _fix.ps1
